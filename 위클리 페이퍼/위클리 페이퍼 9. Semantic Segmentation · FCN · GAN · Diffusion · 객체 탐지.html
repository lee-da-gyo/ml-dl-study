Q1
실습 해설

Semantic Segmentation이란 무엇이며, 이미지 분류(Classification)와 어떤 차이가 있나요?

한 줄 요약

Semantic Segmentation은 이미지의 모든 픽셀에 클래스 라벨을 붙이는 작업이고, 이미지 분류는 이미지 전체에 라벨을 붙이는 작업이다. 둘의 차이는 출력의 단위다.

  • 이미지 분류: 출력이 클래스 점수 벡터 [C] 하나. 무엇이 있는지는 알지만 어디에, 몇 개 있는지는 모른다.
  • Semantic Segmentation: 출력이 클래스 점수 지도 [C, H, W]. 영역과 경계를 알지만 같은 클래스의 객체끼리는 구분하지 않는다.

객체를 하나씩 나누려면 Instance Segmentation, 배경과 객체를 한 장의 지도로 함께 다루려면 Panoptic Segmentation이 필요하다.

from torch import nn

pred_mask = seg_logits.argmax(dim=1)         # [2, 256, 256]: 픽셀마다 클래스 번호

criterion = nn.CrossEntropyLoss(ignore_index=255)  # 255 = 경계 등 평가 제외 픽셀 (VOC 관례)
loss = criterion(seg_logits, target)         # target: [2, 256, 256] 정수 마스크, 픽셀별 손실의 평균

def miou(pred, target, num_classes, ignore_index=255):
    keep = target != ignore_index
    pred, target = pred[keep], target[keep]
    ious = []
    for c in range(num_classes):
        inter = ((pred == c) & (target == c)).sum()
        union = ((pred == c) | (target == c)).sum()
        if union > 0:                         # 예측에도 정답에도 없는 클래스는 평균에서 제외
            ious.append(inter.float() / union.float())
    return torch.stack(ious).mean()          # 논문 수치는 보통 데이터셋 전체 픽셀을 모아서 계산

정정Semantic Segmentation이 픽셀에 붙이는 것은 "어떤 객체"가 아니라 "어떤 클래스"입니다. 자동차가 두 대 있으면 두 대의 픽셀이 모두 같은 '자동차' 라벨을 받고, 어느 픽셀이 몇 번째 자동차인지는 출력에 없습니다(실험 1).

원래 답안의 예시처럼 개와 고양이는 클래스가 달라 영역이 나뉘지만, 개 두 마리가 붙어 있으면 하나의 '개' 영역이 됩니다. 객체 단위의 구분은 Instance Segmentation의 일입니다.

보충 · 분류 모델의 출력 방식

단일 라벨과 다중 라벨

원래 답안의 "개 또는 고양이 중 하나로 분류될 수 있습니다"는 단일 라벨 분류에서 맞는 말입니다. 출력층 구성에 따라 결과가 달라집니다.

  • 단일 라벨: 소프트맥스로 클래스 확률의 합이 1이 되어 하나를 고른다.
  • 다중 라벨: 클래스마다 시그모이드로 독립 확률을 내서 "개 있음 · 고양이 있음"을 함께 말한다.

다중 라벨이어도 위치 · 경계 · 개수는 출력에 없습니다. CAM · Grad-CAM으로 분류 모델의 판단 근거를 히트맵으로 볼 수는 있지만, 이것은 판단에 기여한 부분이지 물체의 정확한 영역이 아닙니다.

보충 · 평가 지표

픽셀 정확도보다 mIoU

배경이 대부분인 이미지에서는 작은 물체를 통째로 놓쳐도 픽셀 정확도가 높게 나옵니다. 그래서 분할 모델은 클래스마다 IoU를 구해 평균한 mIoU로 비교합니다(실험 2).

의료 영상처럼 병변이 아주 작으면 Dice 계수 2|A ∩ B| / (|A| + |B|)를 손실이나 지표로 쓰고, 교차 엔트로피에 클래스 가중치를 주어 클래스 불균형을 다룹니다.

보충 · 실무 비용

픽셀 정답은 만들기 비싸다

Cityscapes 데이터셋 논문(2016)은 정밀 주석 한 장에 품질 검수까지 평균 1.5시간 이상 걸렸다고 보고했습니다. 분할 프로젝트에서는 모델보다 라벨링이 병목이 되는 경우가 많습니다.

그래서 점 · 상자 같은 간단한 입력으로 마스크를 만들어 주는 SAM(Segment Anything, 2023) 같은 모델을 라벨링 보조 도구로 씁니다.

이미지 분류는 이미지 전체에 대해 클래스 점수를 내는 작업이고, Semantic Segmentation은 모든 픽셀에 클래스를 붙여 클래스 맵을 만드는 작업입니다. 그래서 분류는 무엇이 있는지만 알려 주고, 분할은 그것이 어느 영역을 차지하고 경계가 어디인지까지 알려 줍니다.

주의할 점은 Semantic Segmentation이 같은 클래스의 객체를 구분하지 않는다는 것입니다. 자동차 두 대가 붙어 있으면 하나의 자동차 영역이 되므로, 객체별로 나누려면 Instance Segmentation, 배경까지 함께 다루려면 Panoptic Segmentation을 씁니다.

평가는 픽셀 정확도 대신 mIoU를 봅니다. 배경이 대부분이면 작은 물체를 놓쳐도 픽셀 정확도가 높게 나오기 때문입니다. 자율주행의 도로·보행자 영역, 의료 영상의 병변 범위처럼 경계가 중요한 문제에 쓰입니다.

실습 해설

Fully Convolutional Networks(FCN)의 주요 특징과 기존 CNN 기반 분류 모델과의 차이점은 무엇인가요?

한 줄 요약

FCN(Long · Shelhamer · Darrell, CVPR 2015)은 분류용 CNN의 완전 연결층을 같은 가중치의 합성곱으로 바꿔, 이미지 한 장의 점수 벡터 대신 위치마다 클래스 점수를 가진 지도를 출력하게 만든 모델이다. 세 가지가 핵심이다.

  • 합성곱화: fc6 → 7×7 합성곱, fc7 · 분류층 → 1×1 합성곱. 사전 학습 가중치를 그대로 쓰고, 입력 크기 제약이 사라진다.
  • 업샘플링: 1/32로 작아진 점수 지도를 전치 합성곱(bilinear 보간으로 초기화)으로 입력 크기까지 키운다.
  • 스킵 연결: pool4 · pool3의 얕은 특징으로 만든 점수를 더해(FCN-16s · FCN-8s) 경계를 세밀하게 만든다.

업샘플링만으로는 다운샘플링에서 버려진 세부가 돌아오지 않는다. 세밀함은 스킵 연결이 가져온다.

import torch.nn.functional as F

class FCN8sHead(nn.Module):
    def __init__(self, num_classes):
        super().__init__()
        self.score32 = nn.Conv2d(4096, num_classes, 1)    # fc7 → 점수 (1/32)
        self.score16 = nn.Conv2d(512, num_classes, 1)     # pool4 → 점수 (1/16)
        self.score8 = nn.Conv2d(256, num_classes, 1)      # pool3 → 점수 (1/8)
        self.up2a = nn.ConvTranspose2d(num_classes, num_classes, 4, stride=2, padding=1, bias=False)
        self.up2b = nn.ConvTranspose2d(num_classes, num_classes, 4, stride=2, padding=1, bias=False)

    def forward(self, pool3, pool4, fc7, out_size):
        s = self.up2a(self.score32(fc7)) + self.score16(pool4)    # 1/32 → 1/16, 스킵 더하기
        s = self.up2b(s) + self.score8(pool3)                      # 1/16 → 1/8, 스킵 더하기
        return F.interpolate(s, size=out_size, mode="bilinear", align_corners=False)  # 1/8 → 원본

실험 4 전치 합성곱은 출력 칸마다 몇 번 겹치나 입력 4 × 4 · 모든 값과 가중치가 1

전치 합성곱은 입력 칸 하나하나가 커널 크기의 조각을 출력에 stride 간격으로 찍고, 겹치는 곳은 더하는 연산입니다. 입력과 커널을 모두 1로 두면 출력 값이 곧 그 칸에 찍힌 횟수가 됩니다.

출력 크기는 (n − 1) × s − 2p + k입니다(output_padding 0 기준). 커널 크기와 stride를 바꿔 겹침이 고르게 되는 조건을 찾아보세요.

2 · 핵심 정리와 보충
정정 · 실습 해설에서 바로잡을 부분
원래 · 실습 해설그러나 FCN은 완전 연결층을 제거하고, 대신 컨볼루션 연산만을 사용하여 전체 이미지의 공간적 정보를 유지하면서 픽셀 단위로 클래스를 예측할 수 있도록 설계되었습니다.

정정FCN은 완전 연결층을 제거하지 않고 합성곱으로 바꿉니다. fc6의 가중치 행렬 4096 × 25,088을 7×7 합성곱 필터 4,096개로 그대로 옮겨 쓰며(위 코드), 덕분에 ImageNet으로 학습한 분류 가중치를 분할에 재사용할 수 있었습니다. 이것이 FCN의 핵심 전이 학습 방법입니다.

또 "컨볼루션 연산만" 쓰는 것도 아닙니다. ReLU, 최대 풀링, 전치 합성곱 업샘플링, 스킵 더하기, (원 구현의) 크롭이 들어 있습니다. 논문이 말하는 fully convolutional은 모든 층이 합성곱 · 풀링 · 원소별 활성화처럼 국소 영역에만 의존하는 연산이라 어떤 크기의 입력에도 적용된다는 뜻입니다.

원래 · 실습 해설FCN의 가장 큰 특징은 업샘플링(Upsampling) 또는 디컨볼루션(Deconvolution) 연산을 사용하여 입력 이미지와 동일한 크기의 출력을 생성할 수 있다는 점입니다.

정정FCN 논문과 Caffe는 이 층을 'deconvolution'이라고 불렀지만, 수학의 deconvolution(합성곱을 되돌리는 역연산)이 아니라 전치 합성곱(transposed convolution)입니다. 합성곱을 행렬 C로 쓰면 C⁻¹이 아니라 Cᵀ를 곱하는 연산입니다.

예를 들어 [1, 2, 3]을 커널 [1, 1]로 합성곱하면 [3, 5]가 되고, 같은 커널로 전치 합성곱하면 [3, 8, 5]가 됩니다. 크기는 돌아오지만 값은 원래와 다릅니다. PyTorch 이름도 nn.ConvTranspose2d입니다.

원래 · 실습 해설CNN의 다운샘플링(Stride, Pooling) 과정에서 손실된 해상도를 복구하기 위해 FCN은 업샘플링 기법을 활용하여 원본 크기의 예측 맵을 생성합니다. 이를 통해 모델이 픽셀 단위로 세밀한 예측을 수행할 수 있도록 합니다.

정정업샘플링은 크기를 맞출 뿐, 다운샘플링에서 버려진 세부를 되살리지 못합니다. 1/32 점수를 바로 32배 키운 FCN-32s는 경계가 뭉개지고, 실험 3처럼 격자 칸보다 가는 물체는 점수가 완벽해도 사라집니다.

세밀한 예측을 가능하게 한 것은 원래 답안에 빠진 스킵 연결입니다. 해상도가 높은 pool4 · pool3의 점수를 더해 VOC 2011 검증 mean IU가 59.4(FCN-32s) → 62.4(FCN-16s) → 62.7(FCN-8s)로 올랐습니다.

보충 · 입력 크기가 자유로운 이유

미끄러지는 창을 한 번에 계산한다

완전 연결층은 입력 벡터 길이가 고정이라 분류 CNN은 224 × 224 입력만 받습니다. 합성곱화하면 더 큰 입력에서 7 × 7 창을 미끄러뜨리며 분류한 결과가 한 번의 순전파로 나옵니다(위 코드에서 14 × 14 → 8 × 8).

창마다 따로 분류하면 겹치는 부분을 반복 계산하지만, 합성곱은 그 계산을 공유하므로 훨씬 효율적입니다. 이것이 FCN이 "임의 크기 입력"을 처리하는 원리입니다.

보충 · 전치 합성곱의 부작용

체커보드 무늬

커널 크기가 stride로 나누어떨어지지 않으면 출력 칸마다 겹치는 횟수가 달라져 생성 이미지에 격자 모양 얼룩이 생깁니다(Odena et al., 2016 · 실험 4).

  • 커널을 stride의 배수로 둔다 (k = 4, s = 2)
  • bilinear · 최근접 업샘플링 뒤에 3×3 합성곱을 둔다
보충 · FCN 이후

U-Net, DeepLab, 트랜스포머

  • U-Net(2015): 대칭인 인코더-디코더. 스킵을 더하기 대신 채널 이어 붙이기(concat)로 합쳐 의료 영상에서 표준이 되었다.
  • DeepLab: 팽창(atrous) 합성곱으로 해상도를 덜 줄이면서 수용 영역을 넓히고, ASPP로 여러 크기의 문맥을 모은다.
  • SegFormer · Mask2Former: 트랜스포머 기반. Mask2Former는 semantic · instance · panoptic을 한 구조로 처리한다.

FCN은 분류용 CNN의 완전 연결층을 같은 가중치의 합성곱으로 바꿔서, 이미지 한 장의 점수 벡터 대신 위치마다 클래스 점수를 가진 점수 지도를 출력하게 만든 모델입니다. 그래서 사전 학습된 분류 가중치를 그대로 쓰면서 임의 크기의 이미지를 받을 수 있습니다.

다만 풀링을 다섯 번 거치면 점수 지도가 입력의 1/32이 되므로, 전치 합성곱으로 업샘플링해 입력 크기로 키웁니다. 업샘플링만으로는 경계가 뭉개지기 때문에 pool4와 pool3의 얕은 특징으로 만든 점수를 더하는 스킵 연결을 넣었고, 이것이 FCN-16s와 FCN-8s입니다.

정리하면 분류 CNN은 공간 구조를 버리고 클래스 하나를 내지만, FCN은 공간 구조를 끝까지 유지하고 픽셀마다 교차 엔트로피로 학습합니다. 이 구조가 U-Net과 DeepLab 같은 이후 분할 모델의 출발점이 되었습니다.

GAN에서 생성자(Generator)와 판별자(Discriminator)의 역할은 각각 무엇인가요?

한 줄 요약

생성자 G는 잠재 벡터 z를 받아 가짜 데이터 G(z)를 만들고, 판별자 D는 입력이 진짜일 확률 D(x)를 낸다. 둘은 하나의 목적 함수를 두고 D는 키우고 G는 줄이는 미니맥스 게임을 한다.

  • 판별자: 진짜는 1, 가짜는 0으로 맞히는 이진 분류기. G에게 "어디가 가짜 같은지"를 기울기로 알려 주는 학습 신호 역할을 한다.
  • 생성자: 진짜 데이터를 직접 보지 않고, D를 거쳐 온 기울기만으로 D가 "진짜"라고 하도록 출력을 바꾼다.

이론상 균형점은 pg = pdata이고 그때 D는 어디서나 1/2을 낸다. 실제 학습은 수렴이 보장되지 않아 모드 붕괴와 불안정이 생긴다. 학습이 끝나면 생성에는 G만 쓴다.

1 · 그림·표·실험

핵심 두 신경망이 주고받는 것

핵심 목적 함수와 최적 판별자 (Goodfellow et al., 2014)

minG maxD V(D, G) = Ex~pdata[ log D(x) ] + Ez~pz[ log(1 − D(G(z))) ]
D*(x) = pdata(x) / ( pdata(x) + pg(x) )
V(D*, G) = −log 4 + 2 · JSD(pdata ‖ pg)

G를 고정하면 D가 할 일은 진짜와 가짜를 가르는 이진 분류이고, 그 최적해가 D*입니다. D*를 넣으면 G의 목표는 두 분포 사이의 Jensen–Shannon 발산(JSD)을 줄이는 것과 같아지고, JSD = 0인 pg = pdata에서 D*(x) = 1/2이 됩니다.

단, 이 결론은 G와 D가 충분한 용량을 갖고 D를 매번 최적까지 학습한다는 이상적 가정에서 나온 것입니다.

2 · 핵심 정리와 보충
정정 · 실습 해설의 결론에서 바로잡을 부분
원래 · 실습 해설결국, 이 과정이 반복되면서 생성자는 점점 더 실제 데이터와 구별하기 어려운 고품질의 데이터를 생성할 수 있게 됩니다.

정정반복하면 결국 고품질에 도달한다는 보장은 없습니다. pg = pdata로 수렴한다는 결과는 무한한 용량과 매번 최적인 판별자를 가정한 이론이고, 실제 신경망을 번갈아 경사 하강하면 다음 문제가 흔히 생깁니다.

  • 진동 · 발산: 두 손실이 서로를 밀어내며 균형점 주위를 돈다.
  • 모드 붕괴: G가 D를 속이기 쉬운 몇 가지 출력에만 몰린다(실험 5).
  • 기울기 포화: D가 너무 강하면 원래 식의 G 기울기가 0에 가까워진다.

또 G · D의 손실 값은 서로 상대적이라 품질의 척도가 되지 않습니다. 생성 품질은 FID 같은 별도 지표로 평가하고, 안정화에는 non-saturating 손실, WGAN-GP, 스펙트럼 정규화 같은 방법을 씁니다.

보충 · 모드 붕괴가 생기는 이유

생성자에게는 다양성을 요구하는 항이 없다

G의 손실은 "지금의 D를 속였는가"만 묻습니다. 그래서 D가 아직 잘 못 가려내는 출력 하나를 찾으면, 모든 z를 그쪽으로 보내는 것이 당장은 손실을 가장 많이 줄입니다. D가 그 출력을 의심하기 시작하면 G는 다른 출력으로 옮겨 가며 쫓고 쫓기기를 반복합니다.

대응으로는 판별자가 배치 안의 다양성을 보게 하는 미니배치 판별(Salimans et al., 2016), 분포 사이 거리를 Wasserstein 거리로 바꾼 WGAN(Arjovsky et al., 2017) 등이 있습니다.

보충 · 조건부 GAN과 지금의 쓰임새

원하는 것을 생성하고, 빠르게 생성한다

  • 조건부 GAN(Mirza & Osindero, 2014): G(z, y)와 D(x, y)에 조건 y를 함께 넣는다.
  • pix2pix · CycleGAN(2017): 이미지 → 이미지 변환. CycleGAN은 짝이 없는 데이터로 학습한다.
  • StyleGAN(2019): 고해상도 얼굴 생성.

GAN은 한 번의 순전파로 생성해 빠르기 때문에, 지금도 초해상도와 diffusion 모델을 몇 단계로 줄이는 적대적 증류(예: SDXL Turbo의 ADD)에 판별자가 쓰입니다.

GAN은 두 신경망이 경쟁하며 학습하는 생성 모델입니다. 생성자는 정규분포에서 뽑은 잠재 벡터를 받아 가짜 데이터를 만들고, 판별자는 입력이 진짜 데이터일 확률을 내는 이진 분류기입니다.

판별자는 진짜에는 1, 가짜에는 0을 내도록 학습하고, 생성자는 판별자가 가짜를 진짜라고 하도록 학습합니다. 생성자는 진짜 데이터를 직접 보지 않고 판별자를 거쳐 온 기울기로만 배우기 때문에, 판별자는 사실상 생성자의 학습 신호입니다. 이론상 균형점에서는 생성 분포가 데이터 분포와 같아지고 판별자는 어디서나 1/2을 냅니다.

다만 실제로는 수렴이 보장되지 않아 모드 붕괴나 진동이 생깁니다. 그래서 생성자 손실은 원래 식 대신 −log D(G(z))를 쓰고, WGAN-GP나 스펙트럼 정규화로 안정화하며, 품질은 손실이 아니라 FID로 평가합니다.

Diffusion 모델이 이미지 생성에서 어떻게 활용되며, 어떤 장점이 있나요?

한 줄 요약

Diffusion 모델은 데이터에 가우시안 노이즈를 조금씩 더하는 전방향 과정을 미리 정해 두고, 그 반대인 노이즈를 한 단계씩 걷어 내는 역방향 과정을 신경망으로 학습한다.

  • 학습: 시점 t를 무작위로 골라 노이즈 섞인 xt를 한 번에 만들고, 신경망이 넣은 노이즈 ε를 맞히는 MSE 회귀를 한다.
  • 생성: 순수한 노이즈 xT에서 출발해 예측한 노이즈를 조금씩 빼며 수십 ~ 수천 단계를 반복해 새 표본을 얻는다.

장점은 적대적 게임이 없는 안정적인 학습, 높은 품질과 다양성, 텍스트 같은 조건을 거는 유연성이고, 단점은 반복 샘플링 때문에 생성이 느리다는 것이다.

정규분포 노이즈를 여러 번 더한 결과도 정규분포이므로, x0에서 xt를 한 번에 만들 수 있습니다. 그래서 학습은 1,000단계를 차례로 돌지 않고, 배치마다 t를 무작위로 골라 위 MSE 하나를 줄이는 것으로 끝납니다.

import torch
import torch.nn.functional as F

T = 1000
betas = torch.linspace(1e-4, 0.02, T)
alphas = 1 - betas
abar = torch.cumprod(alphas, dim=0)

def train_step(x0):
    t = torch.randint(0, T, (x0.size(0),))      # 배치마다 시점을 무작위로
    eps = torch.randn_like(x0)
    a = abar[t].view(-1, 1, 1, 1)
    xt = a.sqrt() * x0 + (1 - a).sqrt() * eps     # x0에서 xt를 한 번에
    loss = F.mse_loss(model(xt, t), eps)          # 넣은 노이즈를 맞힌다

@torch.no_grad()
def sample(shape):
    x = torch.randn(shape)                        # 순수한 노이즈에서 출발
    for t in reversed(range(T)):
        eps_hat = model(x, torch.full((shape[0],), t))
        mean = (x - betas[t] / (1 - abar[t]).sqrt() * eps_hat) / alphas[t].sqrt()
        x = mean + (betas[t].sqrt() * torch.randn_like(x) if t > 0 else 0)
    return x
2 · 핵심 정리와 보충
정정 · 실습 해설에서 바로잡을 부분
원래 · 실습 해설훈련 과정에서 모델은 노이즈가 추가된 데이터를 보고, 이를 원래 데이터로 복원하는 방법을 학습합니다.

정정대표적인 DDPM의 신경망은 원래 데이터 x0가 아니라 넣은 노이즈 ε를 예측합니다. ε · x0 · v 예측은 위 식으로 서로 바꿀 수 있는 동등한 매개변수화입니다. 최적의 노이즈 예측 ε*는 노이즈 섞인 분포의 score와 ∇log pt(xt) = −ε*(xt, t) / √(1 − ᾱt)로 연결됩니다.

또 학습할 때 체인 전체를 복원하지 않고 t 하나를 골라 한 단계만 학습합니다. 생성할 때도 특정 원본을 되찾는 것이 아니라 학습한 분포에서 새 표본을 뽑는 것입니다(실험 6).

원래 · 실습 해설GAN은 생성자와 판별자 간의 경쟁으로 인해 학습이 불안정해질 수 있지만, Diffusion 모델은 확률적 모델링을 기반으로 하기 때문에 학습이 비교적 안정적입니다.

정정GAN도 데이터의 확률 분포를 학습하는 확률적 생성 모델이므로 "확률적 모델링"은 차이의 이유가 될 수 없습니다.

안정성의 진짜 이유는 목적 함수의 모양입니다. Diffusion은 고정된 정답(넣은 노이즈)에 대한 MSE 회귀 하나를 최소화하므로 상대가 움직이는 미니맥스가 없고, 손실이 로그 가능도의 변분 하한(ELBO)과 연결되어 데이터 전체를 덮도록 학습됩니다.

원래 · 실습 해설기존 생성 모델(GAN, VAE)과 비교했을 때, Diffusion 모델은 더욱 세밀하고 자연스러운 이미지를 생성할 수 있으며, 특정 구조적 결함(예: GAN의 모드 붕괴 문제)이 적습니다.

정정Dhariwal & Nichol(2021)이 ImageNet에서 FID로 당시 최고 GAN(BigGAN-deep)을 앞선 뒤 주류가 된 것은 맞지만, 항상 더 좋은 것은 아닙니다. 품질은 모델 크기 · 데이터 · 샘플링 단계 수 · guidance 강도에 좌우되고, guidance를 세게 주면 충실도는 오르는 대신 다양성이 줄어듭니다.

또 모드 붕괴는 이미지의 구조적 결함이 아니라 생성 결과의 다양성이 줄어드는 현상입니다. Diffusion은 데이터 전체를 덮는 가능도 계열 목적을 쓰기 때문에 모드 붕괴가 드뭅니다. 그리고 원래 답안에는 가장 큰 단점인 느린 생성이 빠져 있습니다.

보충 · 느린 생성을 줄이는 방법

단계를 줄이거나, 단계를 가볍게

  • DDIM(Song et al., 2021): 같은 학습 모델을 결정론적 샘플러로 돌려 50단계 안팎으로 줄인다. 재학습이 필요 없다.
  • Latent Diffusion(Rombach et al., CVPR 2022): 오토인코더로 512 × 512 × 3 이미지를 64 × 64 × 4 잠재로 줄여 그 안에서 확산한다. 단계 수가 아니라 단계당 연산을 줄인 것으로, Stable Diffusion의 바탕이다.
  • 증류: consistency model, 적대적 증류(ADD) 등으로 1 ~ 4단계 생성.
보충 · 텍스트로 조건을 거는 방법

cross-attention과 classifier-free guidance

텍스트 인코더(CLIP, T5 등)가 만든 문장 임베딩을 노이즈 예측 신경망(U-Net이나 트랜스포머)의 cross-attention에 넣습니다. 학습 때 일정 비율로 조건을 비워 두면, 하나의 모델이 조건 있는 예측과 없는 예측을 모두 할 수 있습니다.

ε̂ = εθ(xt, ∅) + w · ( εθ(xt, c) − εθ(xt, ∅) )

이것이 classifier-free guidance(Ho & Salimans, 2022)입니다. w를 키우면 프롬프트 충실도가 오르고 다양성은 줄어듭니다.

보충 · 새 표본인가, 외운 것인가

완벽하게 외운 모델은 학습 데이터를 복제한다

실험 6에서 학습 점만 아는 완벽한 노이즈 예측기는 학습 점을 그대로 재현합니다. 실제 신경망은 유한한 용량과 학습 방식 때문에 이렇게 외우지 않고 매끄럽게 일반화하므로 새 이미지를 만듭니다.

그래도 데이터에 같은 이미지가 많이 중복되면 학습 이미지와 거의 같은 이미지가 생성될 수 있다는 연구가 있습니다(Carlini et al., 2023). 그래서 학습 데이터 중복 제거가 저작권 · 개인정보 측면에서 중요합니다.

Diffusion 모델은 데이터에 노이즈를 조금씩 더하는 전방향 과정을 고정해 두고, 노이즈를 한 단계씩 걷어 내는 역방향 과정을 신경망으로 학습하는 생성 모델입니다. 학습할 때는 시점 t를 무작위로 골라 노이즈를 섞은 이미지를 만들고, 신경망이 넣은 노이즈를 맞히도록 MSE로 학습합니다.

생성할 때는 순수한 노이즈에서 시작해 예측한 노이즈를 조금씩 빼는 과정을 반복해 새 이미지를 샘플링합니다. 텍스트 조건은 cross-attention으로 넣고 classifier-free guidance로 강도를 조절해서 Stable Diffusion 같은 텍스트-이미지 생성에 쓰입니다.

장점은 적대적 게임 없이 회귀 손실 하나를 줄이므로 학습이 안정적이고, 데이터 전체를 덮도록 학습돼 품질과 다양성이 높다는 점입니다. 단점은 반복 샘플링 때문에 느리다는 것이라, DDIM이나 Latent Diffusion, 증류로 단계 수나 단계당 연산을 줄입니다.

원근 · 선반 경계상자는 맞는데 다른 칸에 배정상자 바닥 중심을 호모그래피로 선반 평면에 투영한 뒤 칸 판정
검출 결과 → 신뢰도 임곗값 → 클래스별 NMS → 선반 칸별 개수 → 최근 프레임 중앙값 (torchvision)
from collections import deque
import torch
from torchvision.ops import batched_nms

history = {zone: deque(maxlen=15) for zone in shelf_zones}   # 칸마다 최근 15프레임

def count_frame(det, num_classes):
    boxes, scores, labels = det["boxes"], det["scores"], det["labels"]   # boxes: (x1, y1, x2, y2)
    keep = scores >= 0.5                                                 # 신뢰도 임곗값
    boxes, scores, labels = boxes[keep], scores[keep], labels[keep]
    keep = batched_nms(boxes, scores, labels, iou_threshold=0.6)         # 클래스별 중복 제거
    boxes, labels = boxes[keep], labels[keep]

    foot_x = (boxes[:, 0] + boxes[:, 2]) / 2                             # 상자 바닥 중심
    foot_y = boxes[:, 3]
    for zone, (x1, y1, x2, y2) in shelf_zones.items():
        inside = (foot_x >= x1) & (foot_x < x2) & (foot_y >= y1) & (foot_y < y2)
        counts = torch.bincount(labels[inside], minlength=num_classes)
        history[zone].append(counts.float())

def stable_counts(zone):
    return torch.stack(list(history[zone])).median(dim=0).values         # 가림으로 튀는 값을 무시

정정진열대 재고는 "지금 선반에 몇 개 있나"를 프레임마다 따로 세는 값이라, 여러 프레임의 개수를 더하지 않는 한 중복 집계가 생기지 않습니다. 고정 카메라의 진열대에서 실제 문제는 사람 · 카트가 가려 프레임마다 개수가 흔들리는 것이고, 대응은 가린 프레임을 빼고 여러 프레임 개수의 중앙값을 쓰는 것입니다.

Multi-Object Tracking이 꼭 필요한 경우는 움직이는 대상을 누적해서 셀 때입니다.

  • 고객이 집어 간 상품 수 (손과 상품의 이동)
  • 매장 출입 · 통과 인원
  • 계산대를 지나가는 상품
보충 · 탐지기 출력 형식

상자 좌표 표기는 라이브러리마다 다르다

  • (x1, y1, x2, y2): 왼쪽 위 · 오른쪽 아래 꼭짓점. torchvision이 쓰는 형식
  • (x, y, w, h): 왼쪽 위 꼭짓점 + 너비 · 높이. COCO 주석 형식
  • (cx, cy, w, h): 중심 + 너비 · 높이. YOLO 라벨 형식(이미지 크기로 정규화)

형식을 섞으면 IoU와 NMS가 조용히 틀리므로, 파이프라인 경계에서 변환을 명시해야 합니다.

보충 · 분할로 세면 안 되는 이유

Semantic Segmentation은 붙은 상품을 하나로 합친다

Semantic Segmentation으로 상품 영역은 찾을 수 있지만, 같은 상품이 붙어 있으면 한 덩어리가 되어 개수를 셀 수 없습니다(Q1 실험 1). 개수가 목표라면 객체 탐지나 객체마다 마스크를 내는 Instance Segmentation을 써야 합니다.

이미지 분류 모델은 프레임 전체에 대한 클래스 점수만 내기 때문에, 상품이 있는지는 알 수 있어도 몇 개인지와 어디에 있는지는 출력에 없습니다. 다중 라벨 분류로 바꿔도 여러 상품의 존재 여부만 늘어날 뿐 개수와 위치는 여전히 모릅니다.

객체 탐지는 상품마다 클래스, 신뢰도, 바운딩 박스를 따로 냅니다. 신뢰도 임곗값과 NMS로 중복을 지운 뒤 남은 상자 수가 개수가 되고, 상자의 바닥 중심을 선반 칸에 매핑하면 위치가 됩니다.

실제 매장에서는 상품이 촘촘해 NMS가 이웃 상품을 지우거나 중복 상자가 남을 수 있어 NMS 임곗값을 진열 밀도에 맞추고, 사람이 가린 프레임은 빼고 여러 프레임의 중앙값으로 개수를 안정화하겠습니다. 비슷한 포장은 탐지 후 SKU 임베딩 검색으로 구분하고, 겹침이 심하면 Instance Segmentation까지 검토하겠습니다.
