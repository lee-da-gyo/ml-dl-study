Q1
실습 해설

CNN을 구성하는 각 레이어의 역할에 대해 설명해보세요.

한 줄 요약

CNN은 합성곱층 → 활성화 함수 → 다운샘플링(풀링 또는 stride 합성곱) 블록을 여러 번 쌓아 특징을 뽑고, 마지막 분류 헤드(Flatten + 완전연결층, 또는 Global Average Pooling + 선형층)가 클래스 점수를 내는 신경망이다.

이 구조가 이미지에 잘 맞는 이유는 세 가지다.

  • 지역 연결: 한 출력 칸은 입력의 작은 창(예: 3×3)만 본다
  • 가중치 공유: 같은 필터를 모든 위치에 다시 쓴다
  • 계층적 특징: 층을 쌓을수록 한 칸이 보는 영역(수용 영역)이 넓어져 엣지 → 무늬 → 부분 → 물체로 올라간다

핵심 합성곱 한 칸의 계산과 크기 공식

출력[k, i, j] = bk + Σc Σu Σv W[k, c, u, v] · 입력[c, i·S + u − P, j·S + v − P] 출력 크기 = ⌊(입력 크기 + 2P − K) / S⌋ + 1 K: 필터 크기, P: 패딩, S: stride 파라미터 수 = (K × K × Cin + 1) × Cout C: 채널 수, +1은 편향

필터 하나는 입력의 모든 채널을 한꺼번에 덮는 K × K × Cin 크기의 덩어리이고, 필터 하나가 출력 채널 하나를 만듭니다. 그래서 파라미터 수는 이미지의 가로·세로 크기와 무관합니다. 224×224 이미지든 32×32 이미지든 3×3 필터 64개의 파라미터는 똑같이 1,792개입니다.

같은 특징 추출부에 두 가지 헤드를 붙이고 모양·파라미터 확인하기 (PyTorch)
import torch
from torch import nn

def block(c_in, c_out):                                  # 합성곱 → 정규화 → 활성화 → 다운샘플링
    return nn.Sequential(nn.Conv2d(c_in, c_out, 3, padding=1, bias=False),
                         nn.BatchNorm2d(c_out), nn.ReLU(), nn.MaxPool2d(2))

features = nn.Sequential(block(3, 32), block(32, 64), block(64, 128))
flatten_head = nn.Sequential(nn.Flatten(), nn.Linear(128 * 4 * 4, 256), nn.ReLU(),
                             nn.Dropout(0.5), nn.Linear(256, 10))     # 32×32 입력 전용
gap_head = nn.Sequential(nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(128, 10))

x = torch.randn(8, 3, 32, 32)                            # (배치, 채널, 높이, 너비)
h = features(x)
print(h.shape)                                           # torch.Size([8, 128, 4, 4])
print(flatten_head(h).shape, gap_head(h).shape)          # 둘 다 torch.Size([8, 10])
count = lambda m: sum(p.numel() for p in m.parameters())
print(count(features), count(flatten_head), count(gap_head))   # 93,472 / 527,114 / 1,290
2 · 핵심 정리와 보충
정정 · 원래 답안에서 바로잡을 부분
원래 · 실습 해설Max Pooling은 가장 중요한 값을 선택해 중요한 정보를 보존하고

정정Max Pooling은 창 안에서 가장 큰 활성값을 고를 뿐입니다. 활성값이 크다는 것은 "그 필터의 패턴과 많이 닮았다"는 뜻이지, 의미상 가장 중요한 정보라는 보장은 없습니다.

역전파에서도 기울기는 각 창의 최댓값 위치 하나로만 흐르고 나머지 3칸은 0을 받습니다(실험 1의 초록 칸).

원래 · 실습 해설Pooling Layer는 데이터의 크기를 줄여 계산량을 감소시키고, 모델의 일반화 능력을 높이는 역할을 합니다. … 이를 통해 과적합을 방지하는 효과도 있습니다.

정정풀링 자체에는 학습 파라미터가 없으므로 과적합을 직접 막는 장치가 아닙니다. 영향은 간접적입니다.

  • 도움이 되는 경우: 특징 지도가 작아져 뒤쪽 FC 층의 파라미터가 줄고, 작은 위치 변화에 덜 민감해진다
  • 해가 되는 경우: 위치 정보를 버리므로 분할·검출처럼 정확한 위치가 필요한 작업에서는 성능을 떨어뜨릴 수 있다

과적합 대책은 데이터 증강, 가중치 감쇠, 드롭아웃, 조기 종료가 직접적입니다(위클리 4).

원래 · 작성 답안마지막에는 Global Average Pooling이나 완전연결층이 특징을 종합해 클래스별 예측값을 출력합니다.

정정GAP는 채널마다 평균을 낼 뿐이라 그 자체로는 클래스 점수를 만들지 않습니다. 점수는 GAP 뒤에 붙는 선형층(Linear)이 냅니다.

예외는 마지막 합성곱의 채널 수를 클래스 수와 같게 만들고 GAP 결과를 바로 점수로 쓰는 구조로, 처음 GAP를 제안한 Network in Network(Lin 외, 2013)가 이 방식이었습니다.

보충 · 이름과 다른 실제 연산

딥러닝의 "합성곱"은 교차상관이다

수학의 합성곱은 필터를 뒤집어서 곱하지만, PyTorch nn.Conv2d를 비롯한 딥러닝 프레임워크는 뒤집지 않고 그대로 곱합니다(교차상관, cross-correlation). 필터 값을 학습하므로 뒤집든 안 뒤집든 표현력은 같아 이름만 그대로 쓰는 것입니다.

실험 1의 세로 엣지 필터가 "오른쪽 − 왼쪽"으로 계산되는 것도 뒤집지 않기 때문입니다.

보충 · 3×3 필터를 쌓는 이유

같은 수용 영역을 더 적은 파라미터로

3×3 합성곱 2개를 쌓으면 5×5, 3개를 쌓으면 7×7 영역을 봅니다. 채널이 C로 같을 때 파라미터(편향 제외)를 비교하면 다음과 같습니다.

  • 3×3 세 층: 3 × 9C² = 27C², 그 사이에 ReLU가 2번 더 들어가 비선형성도 늘어난다
  • 7×7 한 층: 49C²

VGG(Simonyan & Zisserman, 2014)가 3×3만 쓴 근거이고, 실험 2의 수용 영역 열에서 3×3 층마다 2칸씩 넓어지다가, 풀링을 지날 때마다 그 증가 폭이 두 배가 되는 것을 볼 수 있습니다.

보충 · 분류 헤드의 변화

큰 FC에서 GAP로, 풀링에서 stride 합성곱으로

VGG-16의 첫 FC 층 하나(25,088 → 4,096)가 1억 276만 개로 전체 1억 3,836만 개의 74%를 차지합니다. 그래서 GoogLeNet·ResNet부터는 GAP + 선형층 하나가 표준이 됐습니다. 입력 해상도가 달라도 GAP 출력 크기는 채널 수로 같다는 장점도 있습니다.

다운샘플링도 All Convolutional Net(Springenberg 외, 2014) 이후 stride 2 합성곱으로 대신하는 구조가 많아졌습니다. 줄이는 방법까지 학습하게 하는 것입니다.

CNN은 합성곱층, 활성화 함수, 다운샘플링 층으로 된 블록을 여러 번 쌓고, 마지막에 분류 헤드를 붙인 구조입니다.

합성곱층은 작은 필터를 이미지 전체에 밀면서 엣지나 무늬 같은 지역 특징을 찾습니다. 한 칸이 가까운 영역만 보는 지역 연결과, 같은 필터를 모든 위치에 쓰는 가중치 공유 덕분에 파라미터가 이미지 크기와 무관하게 적습니다. 그 뒤 ReLU 같은 활성화 함수가 비선형성을 넣고, 풀링이나 stride 2 합성곱이 특징 지도를 줄여 계산량을 낮추고 다음 층이 더 넓은 영역을 보게 합니다. 층이 깊어질수록 특징이 엣지에서 부분, 물체 형태로 올라갑니다.

마지막에는 특징 지도를 펴서 완전연결층에 넣거나, Global Average Pooling으로 채널마다 평균한 뒤 선형층으로 클래스 점수를 냅니다. 큰 완전연결층은 파라미터 대부분을 차지해서 요즘은 GAP 방식을 주로 씁니다. 정규화 층은 학습을 안정시키고 드롭아웃은 과적합을 줄이는 보조 층입니다.

Q2
실습 해설

오토 인코더가 적용되기 적합한 상황에 대해 설명하고, 오토 인코더를 구성하는 인코더(Encoder)와 디코더(Decoder) 각각의 개념과 차이점에 대해 설명하세요.

한 줄 요약

오토인코더는 인코더가 입력 x를 잠재 표현 z = f(x)로 바꾸고, 디코더가 z에서 x̂ = g(z)를 다시 만들어 복원 오차 L(x, x̂)를 줄이도록 함께 학습하는 신경망이다. 정답 레이블 없이 입력 자체가 정답이다.

핵심은 "그대로 복사하지 못하게 막는 제약"이다. 병목(z를 입력보다 작게)이나 잡음·희소성 같은 규제가 있어야 데이터의 구조를 배운다. 그래서 다음 상황에 맞는다.

  • 레이블은 없고 고차원 데이터는 많을 때: 차원 축소, 시각화, 특징 학습
  • 손상된 입력을 고칠 때: 노이즈 제거, 결측 복원
  • 정상 데이터만 충분할 때: 복원 오차를 점수로 쓰는 이상 탐지

새 데이터 생성이 목적이면 잠재 공간의 분포를 정해 두는 VAE가 더 맞다.

차원 축소·시각화학습 후 인코더만 떼어 z를 시각화·군집·검색에 쓴다선형 오토인코더는 PCA와 같은 부분공간을 배운다. 비선형 구조가 있을 때 의미가 있다

합성곱 오토인코더 학습과 복원 오차 기반 이상 탐지 (PyTorch)
import torch
from torch import nn

class ConvAE(nn.Module):
    def __init__(self, z_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(                    # 1×28×28 → 32×14×14 → 64×7×7 → z
            nn.Conv2d(1, 32, 3, stride=2, padding=1), nn.ReLU(),
            nn.Conv2d(32, 64, 3, stride=2, padding=1), nn.ReLU(),
            nn.Flatten(), nn.Linear(64 * 7 * 7, z_dim))
        self.decoder = nn.Sequential(                    # z → 64×7×7 → 32×14×14 → 1×28×28
            nn.Linear(z_dim, 64 * 7 * 7), nn.ReLU(), nn.Unflatten(1, (64, 7, 7)),
            nn.ConvTranspose2d(64, 32, 4, stride=2, padding=1), nn.ReLU(),
            nn.ConvTranspose2d(32, 1, 4, stride=2, padding=1), nn.Sigmoid())

    def forward(self, x):
        return self.decoder(self.encoder(x))

model = ConvAE()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
for x, _ in normal_loader:                               # 레이블은 쓰지 않는다
    x_noisy = (x + 0.2 * torch.randn_like(x)).clamp(0, 1)   # 노이즈 제거용이면 잡음 입력
    loss = nn.functional.mse_loss(model(x_noisy), x)     # 정답은 깨끗한 원본
    opt.zero_grad(set_to_none=True); loss.backward(); opt.step()

@torch.no_grad()
def score(x):                                            # 샘플별 복원 오차
    model.eval()
    return ((model(x) - x) ** 2).flatten(1).mean(dim=1)

threshold = torch.quantile(score(x_val_normal), 0.99)    # 정상 검증 데이터로 임계값
is_anomaly = score(x_test) > threshold
2 · 핵심 정리와 보충
정정 · 실습 해설에서 바로잡을 부분
원래 · 실습 해설이 과정에서 입력 데이터의 중요한 특징만 추출하고, 불필요한 정보를 제거합니다.

정정인코더가 남기는 것은 "중요한 특징"이 아니라 복원 오차를 줄이는 데 유리한 정보입니다. 픽셀 MSE로 학습하면 넓은 배경처럼 픽셀 수가 많은 부분이 우선되고, 분류에 중요한 작은 디테일은 버려질 수 있습니다.

또 병목이 없고 규제도 없으면 아무것도 버리지 않고 그대로 복사하는 법을 배웁니다(실험 3의 선형 오토인코더 · 잠재 차원 2는 복원 오차가 정확히 0).

원래 · 실습 해설디코더는 인코더가 학습한 특징을 기반으로 데이터의 세부 정보를 복원하며

정정디코더는 z에 담긴 정보만 쓸 수 있으므로, 병목에서 사라진 세부 정보는 되살릴 수 없습니다. MSE로 학습한 디코더는 같은 z에 해당할 수 있는 여러 입력의 평균(E[x | z])을 내놓는 쪽으로 학습되어 결과가 흐릿해집니다.

원래 · 실습 해설정상 데이터를 학습한 모델은 이상 데이터를 복원하기 어려워 이 차이를 기반으로 이상치를 탐지할 수 있습니다.

정정이것은 보장이 아니라 가정입니다. 오토인코더가 너무 잘 일반화해서 이상치까지 잘 복원하는 문제는 잘 알려져 있습니다(Gong 외, 2019, MemAE). 실험 3에서 두 경우를 볼 수 있습니다.

  • 정상 패턴 위에 놓인 이상치(빈 구간의 점): 디코더 곡선이 그 위를 지나가 대부분 임계값보다 작은 오차로 복원되므로 놓친다
  • 압축이 없는 모델(잠재 차원 = 입력 차원): 항등 함수를 배울 수 있어, 선형 오토인코더는 이상치까지 오차 0으로 복원한다

그래서 임계값은 정상 검증 데이터로 정하고, 이상 사례가 일부라도 있으면 Precision · Recall · AUROC로 확인해야 합니다.

원래 · 실습 해설마지막으로, 생성 모델링에도 사용되며, 잠재 공간(latent space)을 활용해 새로운 데이터를 생성할 수 있습니다.

정정기본 오토인코더는 복원만 배우고 z의 분포를 정하지 않습니다. 그래서 학습 데이터의 z가 놓인 범위와 그 사이가 의미 있게 채워진다는 보장이 없고, 어디서 z를 뽑아야 할지도 정해져 있지 않습니다(실험 3의 z 슬라이더를 학습 범위 밖으로 옮겨 보세요).

생성에는 KL 항으로 z를 N(0, I)에 맞추는 VAE(Kingma & Welling, 2013)나 확산 모델처럼 확률 분포를 학습하는 모델을 씁니다.

보충 · 병목만이 방법은 아니다

과완전 오토인코더와 규제

z를 입력보다 크게 잡는 과완전(overcomplete) 구조도 쓰지만, 그대로 두면 항등 함수를 배우므로 다른 제약을 겁니다.

  • 희소 AE: z의 대부분이 0이 되도록 L1 같은 벌점을 준다
  • Denoising AE: 손상된 입력에서 원본을 복원하게 해 복사를 막는다
  • Contractive AE: 입력이 조금 바뀌어도 z가 덜 바뀌도록 인코더의 야코비안에 벌점을 준다(Rifai 외, 2011)

따라서 표의 "인코더는 차원을 줄인다"는 가장 흔한 형태일 뿐 정의는 아닙니다.

보충 · PCA와의 관계

선형이면 PCA, 비선형이면 휘어진 구조까지

활성화 없는 오토인코더를 MSE로 학습하면 최적해가 PCA 주성분과 같은 부분공간을 펼칩니다(Baldi & Hornik, 1989). 다만 축이 서로 직교하거나 분산 순서로 정렬된다는 보장은 없습니다.

비선형 오토인코더는 곡선·곡면 같은 구조를 따라 압축할 수 있어, Hinton & Salakhutdinov(2006)는 깊은 오토인코더가 PCA보다 복원 오차가 훨씬 작은 저차원 표현을 만든다는 것을 보였습니다. 실험 3에서 선형과 비선형을 바꿔 비교해 보세요.

보충 · VAE가 다른 점

점이 아니라 분포로 인코딩한다

VAE의 인코더는 z 하나가 아니라 평균 μ(x)와 분산 σ²(x)를 내고, 그 분포에서 z를 뽑아 디코딩합니다. 손실은 두 항입니다.

loss = 복원 오차(x, x̂) + KL( N(μ, σ²) ‖ N(0, I) )

KL 항이 모든 z를 N(0, I) 근처에 모으므로, 생성할 때 N(0, I)에서 z를 뽑으면 디코더가 본 적 있는 영역이 나옵니다.

오토인코더는 입력을 잠재 표현으로 압축했다가 다시 복원하면서, 복원 오차를 줄이도록 학습하는 신경망입니다. 레이블이 필요 없어서, 고차원 데이터는 많은데 레이블이 없을 때의 차원 축소와 특징 학습, 잡음 섞인 입력에서 원본을 복원하는 노이즈 제거, 정상 데이터만 충분할 때의 이상 탐지에 적합합니다.

인코더는 입력을 저차원 잠재 벡터로 바꾸는 부분으로, 복원에 필요한 정보를 그 벡터에 담도록 학습됩니다. 디코더는 그 벡터에서 원래 차원의 데이터를 다시 만드는 부분입니다. 방향이 반대이고, 인코더는 학습 후 특징 추출기로, 디코더는 잠재 벡터를 데이터로 바꾸는 생성기로 따로 쓸 수 있다는 점이 다릅니다.

주의할 점은 두 가지입니다. 병목이나 규제가 없으면 그냥 복사를 배우고, 이상치도 잘 복원될 수 있어서 이상 탐지 임계값은 정상 검증 데이터로 정해야 합니다. 그리고 기본 오토인코더는 잠재 공간의 분포를 정하지 않으므로, 새 데이터 생성이 목적이면 VAE를 쓰겠습니다.

이미지 분류 모델을 완전연결층(Fully Connected Layer)만으로 만들었더니 파라미터 수가 수백만 개를 넘고, 사진 속 물체 위치가 조금만 바뀌어도 예측이 크게 달라져요. 왜 이런 문제가 생기고, CNN은 이 문제를 어떻게 해결하는지 설명해 주세요.

한 줄 요약

완전연결층은 이미지를 순서 없는 숫자 목록으로 본다. 모든 픽셀이 모든 뉴런과 위치마다 다른 가중치로 연결되므로 두 문제가 같은 뿌리에서 나온다.

  • 파라미터 폭증: 파라미터 = 픽셀 수 × 뉴런 수. 224×224×3 입력을 뉴런 1,000개에 연결하면 1억 5천만 개다
  • 위치 민감: 같은 귀라도 다른 위치에 있으면 다른 가중치와 곱해진다. 학습 때 그 위치에서 본 적이 없으면 알아보지 못한다

CNN은 지역 연결로 파라미터를 줄이고, 가중치 공유로 같은 필터를 모든 위치에 써서 이동 등변성을 얻는다. 여기에 풀링·GAP가 위치를 지우면 작은 이동에 대한 근사적 불변성이 생긴다.

핵심 문제와 원인, CNN의 해결 원리

문제완전연결층에서의 원인CNN의 해결 원리남는 한계
파라미터 폭증입력 픽셀 수 × 출력 뉴런 수. 해상도가 2배면 픽셀이 4배, 파라미터도 4배지역 연결 + 가중치 공유로 파라미터가 해상도와 무관Flatten + FC 헤드를 쓰면 헤드에서 다시 커진다(실험 2)
위치 민감위치마다 별도 가중치. 패턴이 지나가지 않은 픽셀의 가중치는 학습되지 않는다같은 필터를 모든 위치에 적용(등변) + 풀링·GAP로 위치 제거(불변)stride·풀링의 다운샘플링 때문에 1픽셀 이동에도 출력이 흔들릴 수 있다
공간 구조 무시픽셀 순서를 섞어도 같은 모델이 된다. 이웃 관계를 데이터로부터 배워야 한다이웃한 픽셀끼리만 묶어서 보는 지역성을 구조에 넣는다멀리 떨어진 부분의 관계는 층을 쌓아야 본다
과적합·데이터 요구파라미터가 많고 같은 패턴을 위치마다 따로 배워야 한다한 위치에서 배운 필터가 모든 위치에 쓰여 데이터 효율이 높다회전·크기 변화에는 구조적 보장이 없어 데이터 증강이 필요하다
실험 4 물체를 처음 보는 위치로 옮기면? FC와 CNN 직접 학습하기 예시 데이터 · 16×16 이미지, '+' 대 '×'

16×16 이미지에 5×5 크기의 '+' 또는 '×'를 넣고(밝기 0.7~1.0, 잡음 σ = 0.15) 둘을 구분하는 세 모델을 이 페이지에서 학습합니다(학습 600장, Adam, 40 에포크).

  • FC: 256 → 32(ReLU) → 1
  • Conv + Flatten: 3×3 필터 4개(ReLU) → 14×14×4를 펴서 → 1
  • Conv + GAP: 3×3 필터 4개(ReLU) → 채널별 평균 4개 → 1

학습 데이터의 물체는 왼쪽(가로 위치 px 0~3)에만 놓입니다. 시험은 px 0~11 모든 위치에서 위치마다 80장씩 합니다. 학습 위치를 "전체"로 바꾸면 모든 위치를 보여 주는 데이터 증강과 같은 효과입니다.

계산 중…

합성곱의 등변성, GAP의 불변성, 다운샘플링이 등변성을 깨는 것을 직접 확인하기 (PyTorch)
import torch
from torch import nn

torch.manual_seed(0)
conv = nn.Conv2d(3, 8, 3, padding=1, bias=False)
x = torch.zeros(1, 3, 32, 32)
x[..., 8:14, 8:14] = torch.rand(3, 6, 6)                 # 가장자리에서 떨어진 물체
x4 = torch.roll(x, shifts=4, dims=3)                     # 오른쪽으로 4칸 이동

y, y4 = conv(x), conv(x4)
print(torch.allclose(torch.roll(y, 4, dims=3), y4, atol=1e-6))    # True: 등변
gap = lambda t: torch.relu(t).mean(dim=(2, 3))
print(torch.allclose(gap(y), gap(y4), atol=1e-6))       # True: GAP 뒤에는 불변

pool = nn.MaxPool2d(2)
y1 = conv(torch.roll(x, shifts=1, dims=3))               # 1칸 이동 + 2×2 풀링
print(torch.allclose(pool(y), pool(y1)))                 # False: 풀링만으로는 불변이 아니다
2 · 핵심 정리와 보충
정정 · 작성 답안에서 바로잡을 부분
원래 · 작성 답안물체 이동에 민감 | 위치마다 별도의 가중치를 학습 | 같은 필터를 모든 위치에 적용

정정"같은 필터를 모든 위치에 적용"만으로는 위치 민감성이 해결되지 않습니다. 합성곱이 주는 것은 특징 지도가 같이 이동하는 등변성이고, 그 지도를 Flatten + FC에 넣으면 위치마다 다른 가중치가 다시 등장합니다.

실험 4에서 Conv + Flatten은 처음 보는 위치에서 FC처럼 정확도가 떨어지고, Conv + GAP만 유지됩니다. 해결의 완성은 등변한 특징 추출 + 위치를 지우는 헤드(풀링·GAP)이고, 작성 답안의 뒷부분 정정 문단은 이 점을 바르게 설명했습니다.

보충 · 실제 CNN은 1픽셀 이동에도 흔들린다

다운샘플링의 앨리어싱과 패딩

stride 2 합성곱이나 2×2 풀링은 출력을 한 칸 걸러 뽑는 것이라, 입력이 홀수 칸 이동하면 출력 격자에 맞지 않습니다. 그러면 출력이 입력을 따라 옮겨지지 못하고 값이 바뀌거나, 반대로 이동이 아예 사라지기도 합니다(실험 1의 stride 2 + 1칸 이동). Azulay & Weiss(2019)는 ImageNet 분류 CNN의 예측이 1픽셀 이동에도 크게 바뀔 수 있음을 보였습니다.

  • 대책: 다운샘플링 전에 흐림 필터를 넣는 안티앨리어싱(BlurPool, Zhang 2019), random crop·translation 증강
  • 패딩: 가장자리의 0 패딩이 "여기는 경계"라는 신호가 되어 CNN도 절대 위치를 어느 정도 알아낸다(Islam 외, 2020)
보충 · 귀납 편향

CNN은 가정을 구조에 넣은 모델이다

"가까운 픽셀끼리 관련 있다(지역성)"와 "같은 패턴은 어디에나 나타날 수 있다(이동 등변성)"는 가정을 구조에 넣었기 때문에 적은 파라미터와 데이터로 학습됩니다. 가정이 맞는 이미지·음성에서 강한 이유입니다.

반대로 Vision Transformer(Dosovitskiy 외, 2020)는 이 가정이 약해서 ImageNet 규모에서는 비슷한 크기의 ResNet보다 낮았고, 3억 장 규모(JFT-300M)로 사전 학습했을 때 앞섰습니다. 가정을 줄이면 데이터가 그만큼 더 필요하다는 예입니다.

완전연결층은 이미지를 한 줄로 편 숫자 목록으로 보고 모든 픽셀을 모든 뉴런에 위치마다 다른 가중치로 연결합니다. 그래서 파라미터가 픽셀 수 곱하기 뉴런 수로 늘어나, 224×224 컬러 이미지를 뉴런 1,000개에 연결하기만 해도 1억 5천만 개가 됩니다. 같은 이유로, 같은 물체도 위치가 바뀌면 전혀 다른 가중치와 곱해지고, 학습 때 물체가 지나가지 않은 위치의 가중치는 학습되지 않아 예측이 크게 흔들립니다.

CNN은 두 가지로 해결합니다. 지역 연결로 한 출력이 3×3 같은 작은 영역만 보게 하고, 가중치 공유로 같은 필터를 모든 위치에 다시 씁니다. 그러면 파라미터가 해상도와 무관하게 줄고, 한 위치에서 배운 특징을 다른 위치에서도 그대로 찾을 수 있습니다. 이때 특징 지도는 입력과 같이 이동하는 이동 등변성을 가집니다.

예측까지 안정되려면 풀링이나 Global Average Pooling으로 위치 정보를 지워야 합니다. 특징 지도를 Flatten해서 FC에 넣으면 위치별 가중치가 다시 생기기 때문입니다. 실제 CNN도 stride와 풀링 때문에 1픽셀 이동에 흔들릴 수 있어서, 데이터 증강이나 안티앨리어싱을 함께 쓰겠습니다.
