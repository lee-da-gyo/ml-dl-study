# 스프린트 미션 1 · Python 연습

파이썬 기초부터 객체와 클래스, 심화 문제까지 풀고 실행 결과를 정리했습니다.

📓 **[미션1_Python_연습.ipynb](미션1_Python_연습.ipynb)**: 문제, 풀이, 실행 결과가 모두 들어 있습니다.

## 문제 구성

| 구분 | 문제 | 풀이 포인트 |
| --- | --- | --- |
| 파이썬 기초 | 3의 배수 · 모음 제거 · 수 비교 · 문자열 길이 · 총합 · 짝수 합 · 나누기 | 가우스 공식(O(1)), `set` + `join`, `try-except`로 0 나누기와 잘못된 입력 처리 |
| 파이썬 응용 | 문자열 압축 · 덧셈 프로그램 · 카운트다운 | 직접 구현한 압축과 `groupby` 압축의 결과 비교, 정수가 들어올 때까지 다시 입력받기 |
| 클래스 기초 | TimeTracker · Contact | `total_seconds()`로 하루가 넘는 시간도 계산, `None`으로 측정 전 상태 표시 |
| 클래스 응용 | 투표 · 은행 계좌 · 직원 관리 · 레스토랑 예약 | 인스턴스 변수와 클래스 변수 구분, 금액·날짜·인원 검증, 예약 취소, 클래스 메서드로 합산 |
| 심화 | 시간 관리 · 소수의 합 · 도서관 관리 | ① 개수 최대 ② 남는 시간 최소 기준으로 할 일 선택, 에라토스테네스의 체, 사용자 정의 예외 |

## 구현하며 신경 쓴 점

| 포인트 | 예시 |
| --- | --- |
| 출제된 함수 형식과 기대 출력을 그대로 지키기 | 모든 문제의 실행 결과가 문제의 예상 출력과 일치 |
| 상태를 둘 위치를 목적에 맞게 구분 | 투표·예약은 인스턴스 변수로 시스템마다 분리, 직원 목록은 클래스 변수로 공유 |
| 잘못된 입력은 멈추지 않고 안내 | 0으로 나누기, 문자 입력, 잔액 초과 출금, 잘못된 날짜·인원, 없는 도서·회원 |
| 놓치기 쉬운 경계 사례 확인 | `//`가 아닌 `/` 나눗셈, `.seconds` 대신 `total_seconds()`, 동명이인 급여, 음수 타이머 |
| 다른 방법으로 구한 답과 비교 | 공식 vs 반복문 합, 직접 구현 vs `groupby`, 에라토스테네스의 체 vs 하나씩 소수 판별 |

## 실행 방법

Python 3.10 이상, 표준 라이브러리만 사용합니다. Jupyter에서 **Restart & Run All**로 실행하면 됩니다.

`input()`이 필요한 문제는 노트북 앞쪽의 `fake_inputs(...)` 도우미로 정해 둔 입력값을 넣어 실행합니다. 직접 입력해 보려면 `with fake_inputs(...)` 없이 함수만 호출하세요.
